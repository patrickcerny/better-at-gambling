# Decisions

Format: date, decision, reason, alternatives rejected.

## 2026-10-04 — Godot 4.7.2 (latest stable) instead of "≥ 4.4"
The prompt asks for the latest stable 4.x. 4.7.2-stable was the newest release on GitHub at M0
(4.7.3 and 4.8 did not exist). Pinned with SHA-512 in `tools/setup_toolchain.sh`.
If GodotSteam (M8) lacks a 4.7 build, re-pin per §3.4. Rejected: older LTS-style pin (no reason to lag).

## 2026-10-04 — GUT 9.7.1 vendored in `addons/gut/`
GUT is ~3 MB of GDScript (MIT). Vendoring makes `scripts/test.sh` work right after clone without
network. The setup script re-fetches it only if missing. Rejected: gitignored + always fetched
(test runs would depend on GitHub availability).

## 2026-10-04 — Steam autoload is named `SteamSvc`, not `Steam`
GodotSteam registers an engine singleton named `Steam`; an autoload with the same name would
collide. Everything goes through `SteamSvc` (stub now, real service in M8).

## 2026-10-04 — Input map generated by `tools/gen_input_map.gd`
Serialized `InputEvent` objects in `project.godot` are verbose and error-prone to hand-edit. The
script is the source of truth for default bindings; run it after changing bindings. All events use
device -1 (any device). Gamepad mapping follows SDL button indices (A=0, B=1, X=2, Y=3, Back/View=4,
Start=6, L3=7, LB=9, RB=10, D-pad up/down/left/right=11/12/13/14, RT=axis 5).
Note: in-match context decides which overlapping action is live (e.g. `item_1` vs `bet_chip_1` on
key 1; `bet_confirm` vs `jump` on Space) since the station UI consumes input while seated.

## 2026-10-04 — Untyped declarations are compile errors
`debug/gdscript/warnings/untyped_declaration=2` makes the engine reject untyped vars/params in project
code (addons excluded). `scripts/lint.sh` loads every script via `tools/check_scripts.gd` so this is
enforced in the test gate, plus a grep for bare `print()` outside `Log`.

## 2026-10-04 — Window override 1280×720, design resolution 1920×1080
The viewport is designed at 1920×1080 (`canvas_items` + `expand`), but the default window opens at
1280×720 so it fits on laptop screens. Settings (M9) will expose window mode/resolution.

## 2026-10-04 — Dedicated server export preset from M0
A `Linux Server` preset (`dedicated_server=true`) exists from the start so server builds can be
smoke-tested early; the `--server` boot path itself lands in M3.
